3. Architecture Selection Analysis

ResNet-18 (Champion Backbone)

Standard dense 2D convolutions maximize arithmetic intensity and memory bandwidth on both GPU Tensor Cores and modern CPU caches. Achieves 95.12% holdout accuracy, 86.70% Improper Mask F1, and 146.6 FPS on CPU / 802 FPS on GPU.

MobileNetV3-Large (Fastest CPU)

Hard-swish activations and optimized inverted residual blocks yield the highest pure CPU frame rate at 184.6 FPS (5.42 ms) with a compact 17.0 MB footprint and 92.44% accuracy. Ideal for low-power edge nodes.

EfficientNet-B0 & MobileNetV2

EfficientNet achieves strong parameter economy (91.38% acc with 5.3M params) but depthwise blocks add CPU overhead (103.4 FPS). MobileNetV2 is ultralight (9.2 MB) but exhibits lower margin separation on subtle improper mask boundaries.
